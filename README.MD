# Мои проекты
### Task Manager
Репозиторий: https://github.com/NetherDon/TaskManager
<br><br> Приложение для создания и управления задачами. Поддерживает авторизацию пользователей. Пользователи могут иметь только две роли: обычный пользватель и администратор.

### Онлайн-конвертер
Репозиторий: https://github.com/NetherDon/Lang-Converter
<br><br> Веб-приложение для конвертации кода из одного языка программирования в другой. Было создано во время работы над ВКР магистра. На данный момент включает в себя только неполный конвертер из языка C# в Java, включающий в себя базовые кострукции языка.

### Генератор конвертеров
Репозиторий: https://github.com/NetherDon/Lang-Converter-Gen
<br><br>Вспомогательный инструмент, созданный для автоматизации сборки конвертеров, созданных на основе лексического анализатора Coco/R.
